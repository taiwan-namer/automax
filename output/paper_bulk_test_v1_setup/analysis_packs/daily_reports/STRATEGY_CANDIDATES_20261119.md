# 策略調整候選摘要（2026-11-19 試產資料）

狀態：**提案／條件子集診斷** — 未改策略、未部署、不批准開新倉。  
與管理可靠性修復**分離**。費率為紙上模擬，非真實帳戶費率。

## 優先 3 項

### 1. CAND_COST_THRESHOLD — 成本門檻／進場與目標相容性
- 證據：完整平倉樣本上，來回費用相對初始風險中位約 **0.34**，>0.25 約 **68%**，>0.40 約 **38%**（以當日試產 metrics 為準；重跑可能微變）。
- 候選：提高最小風險距離或名義／目標 R 與費用相容檢查；**不**以放寬止損稀释比例。
- 缺口：真實費率、拒絕樣本、滑價僅模型。
- 下一步：條件子集診斷（高 fee/risk 子集淨利）→ 少量門檻候選 → 後續日期樣本外。
- **值得下一階段驗證**；**待批准**。

### 2. CAND_BATCH_SAME_DIR — 同批同向集中曝險
- 證據：30s 窗內同向集群數 ≥1（試產見多筆，含 6 標的同向批次）。
- 候選：每批風險預算、當時評分排序取捨、同向名義／初始風險上限；保留決策只能用當時資訊。
- 缺口：若排序分數未落盤則無法公正重放；跳過單改變後續機會。
- **值得下一階段**；標記為子集診斷非完整回測；**待批准**。

### 3. CAND_BREAKOUT_QUALITY — 突破品質濾網（全樣本）
- 證據：當日完整平倉退出以 INITIAL_STOP 為主、TRAILING_STOP 少數；需對**全部**符合條件成交做特徵對照，不挑故事單。
- 候選：訊號棒／事前趨勢／波動分位；僅用已閉合 10m／15m。
- 禁止：用 1m OHLC 捏造 book 成交路徑；進場後 1–5m 報酬不得當進場特徵。
- 完整回測若缺宇宙拒絕日誌 → 列需求，不虛構。
- **值得下一階段（診斷）**；**待批准**。

- 不與管理修復（due 插隊、book 短預算、完成事件）混為同一變更包。
